# 一括ページスクリーンショットツール

> 環境メモ: 環境変数（`HTTPS_PROXY` など）にプロキシ設定がある環境では、ローカル中継を自動で挟んで接続します。一部のプロキシは Chromium からの直接接続を受け付けないためです。通常のネットワークでは中継なしで直接つながります。

複数のWebページを、PNGかJPEGの画像にまとめて保存するCLIツールです。Playwright（Chromium）を使います。

## 使い方

URLを引数で渡す場合:

```sh
node screenshot.mjs https://example.com https://example.org/about
```

URLリストのファイルから読む場合:

```sh
node screenshot.mjs --file urls.txt
```

`urls.txt` には1行に1つURLを書きます。`#` で始まる行はコメント扱いで、空行は無視します。`--file` と引数のURLは一緒に使えます。

### オプション

| オプション | 内容 | デフォルト |
| --- | --- | --- |
| `--file <path>` | URLリストのファイルを読む | なし |
| `--out <dir>` | 出力先のディレクトリ。なければ作る | `./shots` |
| `--width <px>` | ビューポートの幅。高さは900で固定 | `1440` |
| `--viewport` | 表示範囲だけを撮る。付けなければページ全体を撮る | 付けない |
| `--wait <ms>` | ページ読み込み後に待つミリ秒 | `1000` |
| `--format png\|jpeg` | 画像形式 | `png` |

### セットアップ

Node.js が必要です。初回だけ次を実行してください。

```sh
npm install
npx playwright install chromium
```

## 出力

画像は出力先に `001-example.com.png` のような名前で保存します。先頭は3桁の連番で、その後ろにホスト名とパスから作った名前（最大60文字）が付きます。

1件ごとに `OK <ファイル名> (<幅>x<高さ>px)` か `FAIL <URL> <理由>` を表示し、最後に `完了: 成功X件 / 失敗Y件` を表示します。失敗したURLがあっても残りは続けて撮ります。1件でも成功すれば終了コードは0、全部失敗すると1です。

## 注意

ログインが必要なページは撮れません。
