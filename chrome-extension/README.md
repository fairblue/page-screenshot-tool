# ページ全体スクリーンショット（Chrome拡張機能）

今見ているタブのページ全体を、1枚のPNG画像にしてダウンロードします。

## 導入手順

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダ（`chrome-extension`）を選ぶ

## 使い方

次のどれかで撮影が始まります。

- ツールバーの拡張機能ボタンを押す
- `Command+Shift+S`（Mac）／`Ctrl+Shift+S`（Windows・Linux）を押す
- ページ上で右クリックして「ページ全体を画像で保存」を選ぶ

撮影中はボタンのバッジに進み具合（例：`3/12`）が出て、終わると `✓`、失敗すると `!` に変わります。画像は `ホスト名-日付-時刻.png` の名前でダウンロードフォルダに保存されます。

## 注意

- 固定表示（`position: fixed`）のヘッダーなどは、各タイルに写り込みます。
- 極端に長いページは、画像の高さが16384pxに収まるよう自動で縮小されます。
- `chrome://` のページは撮れません。
- ログインが必要なページも、自分のChromeで開いていれば撮れます。
