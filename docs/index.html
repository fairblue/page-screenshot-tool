page-screenshot-tool

ページ全体スクリーンショット

Webページの全体を、1枚のPNGに。Chrome拡張＋一括保存CLI、オープンソースで公開中。

GitHubで見る

特徴

  • 01

    ページ全体を1枚に

    自動スクロールしながら撮影し、1枚のPNGにつなぎ合わせます。

  • 02

    データ収集ゼロ

    コードはすべて公開、MITライセンス。利用状況データを外部に送ることはありません。

  • 03

    2つの形

    Chrome拡張はログイン中のページも撮影可能。CLIはURLリストを一括保存でき、AIへの受け渡しやページの記録に便利です。

使い方

Chrome拡張の導入

  1. chrome://extensions を開く
  2. 「デベロッパーモード」をオンにする
  3. 「パッケージ化されていない拡張機能を読み込む」でフォルダを選ぶ

撮影する

  • ボタンツールバーのボタンを押す
  • ショートカット⌘+Shift+S（Mac）・Ctrl+Shift+S（Windows）
  • 右クリックメニュー「ページ全体を画像で保存」

CLIで一括保存

$ ./shot.sh --file urls.txt

URLを引数で複数渡すこともできます。

よくある質問

無料ですか？

はい。オープンソース（MITライセンス）で、無料で使えます。

ログインが必要なページは撮れますか？

Chrome拡張は今見ているタブを撮影するので、ログイン中のページも撮れます。

とても長いページはどうなりますか？

画像サイズの上限に合わせて、自動で縮小して保存されます。
