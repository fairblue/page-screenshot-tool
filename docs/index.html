page-screenshot-tool

ページ全体スクリーンショット

Webページの全体を、1枚のPNGに。Chrome拡張＋一括保存CLI、オープンソースで公開中。

GitHubで見る

特徴

  • 01

    ページ全体を1枚に

    自動スクロールしながら撮影し、1枚のPNGにつなぎ合わせます。

  • 02

    データ収集ゼロ

    コードはすべて公開、MITライセンス。利用状況データを外部に送ることはありません。

  • 03

    2つの形

    Chrome拡張はログイン中のページも撮影可能。CLIはURLリストを一括保存でき、AIへの受け渡しやページの記録に便利です。

使い方

Chrome拡張の導入

  1. 拡張機能のフォルダをダウンロードする

    GitHubのページから「Code」→「Download ZIP」でダウンロードし、展開しておきます。

  2. Chromeに読み込む

    Chromeで chrome://extensions を開き、右上の「デベロッパーモード」をオンにします。

    「パッケージ化されていない拡張機能を読み込む」を押し、ダウンロードしたフォルダの中の chrome-extension フォルダを選びます。

  3. ボタンを押して撮る

    保存したいページを開いて、ツールバーのボタンを押すだけです。

    ショートカット ⌘+Shift+S（Windowsは Ctrl+Shift+S）や、右クリックメニューの「ページ全体を画像で保存」でも撮れます。

  • 所要時間は約2分です
  • Chromeウェブストアへの登録は準備中です

CLIで一括保存

$ git clone https://github.com/fairblue/page-screenshot-tool
$ cd page-screenshot-tool/cli
$ npm install
$ npx playwright install chromium
$ ./shot.sh https://example.com

URLは複数並べられます。./shot.sh --file urls.txt で、ファイルに書いたURLをまとめて保存することもできます。

スマホでページ全体を撮りたい方へ

このツールはパソコン専用です。スマホのChromeでは拡張機能が使えないためです。スマホでは、OS標準の機能で無料でページ全体を保存できます。

  • iPhoneの場合

    1. Safariでページを開く
    2. スクリーンショットを撮る
    3. 左下に出るプレビューをタップして「フルページ」を選ぶ
    4. 「完了」から「写真に保存」を選ぶ

    これでページ全体が画像として保存されます。

  • Androidの場合

    次のどちらかの方法で撮れます。

    1. Chromeの「共有」メニューから「ロングスクリーンショット」を使う
    2. 電源ボタン＋音量ボタンでスクリーンショットを撮り、「キャプチャ範囲を拡大」を使う

よくある質問

無料ですか？

はい。オープンソース（MITライセンス）で、無料で使えます。

ログインが必要なページは撮れますか？

Chrome拡張は今見ているタブを撮影するので、ログイン中のページも撮れます。

とても長いページはどうなりますか？

画像サイズの上限に合わせて、自動で縮小して保存されます。
